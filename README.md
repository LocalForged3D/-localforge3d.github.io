# LocalForge 3D
https://localforged3d.github.io/-localforge3d.github.io/

Mobile-first Three.js modeler with object transforms, manual mesh editing, sculpting and procedural modifier nodes.

## GitHub Pages
Deploy `main` from `/ (root)`. No build command is required.

## Runtime layout
- `index.html` — website shell
- `assets/css/app.css` — UI
- `assets/js/app.js` — LocalForge modeling core
- `vendor/three/` — local Three.js ES-module runtime
